# Reference images

**No image files are stored here.** Product screenshots for Dots and Grok Bot
are the copyright of their respective owners and are not freely reusable for
redistribution, so they are **linked** from
[`../dots-grokbot-analysis.md`](../dots-grokbot-analysis.md) rather than copied
into the repository. This directory exists so the decision is explicit and a
future maintainer does not wonder why it is empty.

If a genuinely freely-licensed asset is found later, add it here with its licence
and attribution in this file.
